🚀 TO DEPLOY TO MAMMOTHCOAT.COM (3 SIMPLE STEPS):

STEP 1: Run the deployment script (handles GitHub & provides Vercel guidance)

  PowerShell:     .\deploy.ps1
  Command Prompt: deploy.bat

STEP 2: When prompted, create a GitHub repository at https://github.com/new

  Name:           mammoth-coatings
  Type:           Private (recommended)
  Click:          "Create repository"
  Copy:           The HTTPS URL shown

STEP 3: Go to https://vercel.com

  1. Sign in (or create account)
  2. Click "+ New Project"
  3. Import your GitHub repo
  4. Click "Deploy" (takes 2-3 minutes)
  5. Add custom domain: mammothcoat.com
  6. Use Vercel nameservers or add DNS records

Note: After DNS propagates (5-30 min), your site goes live at https://mammothcoat.com
